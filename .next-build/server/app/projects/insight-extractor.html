Why reviews

E-commerce search fails silently, and the fix lives in the only dataset that will tell you why: reviews. People don't file tickets for a dead-end search, but they do review the app that failed them.

The datasetthe only dataset that will tell you why: reviews

The mechanism

I built an agentic extractor on the Reddit, App Store and Play Store APIs that pulls raw review text at scale, then a 6-stage SQL pipeline that cleans, deduplicates and tags it. Across 94.6K reviews the pipeline isolates the root causes of search failure instead of one fuzzy complaint category.

The pipelinea 6-stage SQL pipeline that cleans, deduplicates and tags itThe outputthe root causes of search failure

Four root causes, four treatments

The mining surfaced four causes: vague intent, missing filter context, spelling and slang drift, and catalog gaps that no query could ever fix. Each cause got its own treatment instead of one generic "no results" page.

Pull quoteSelect any line to reply

What it informed

The causes became the product plan for AskCart: a guided follow-up flow for vague intent and missing context, and a semantic fallback for the code-mixed queries the lexicon never reaches. The extractor still runs as the eval source of truth for the search index.
